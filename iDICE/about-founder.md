# About the Founder

I was born in Port Harcourt to Imo State (Mbaise) parents, raised in Benin City, graduated from Madonna University, and currently pursuing my master's in Canada.

**Experience:** Software Engineer at Dowell Research Institute (building web applications), Computer Engineer Intern at NNPC, and Freelance Software Developer.

**Skills:** I build websites and software systems using modern tools like Python and React. I create databases to store information, deploy applications to the cloud, and use AI to automate tasks like grading exams.

**Why Ambezi:** I experienced paper-based examinations at Madonna University. Friends from UNIBEN and UNN face missing scripts and delayed results. In 2026, UNN students faced a major crisis with missing exam papers. I'm building Ambezi to fix this for all 463 Nigerian tertiary institutions.
