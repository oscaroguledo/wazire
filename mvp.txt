# 🎯 MVP GOAL (Keep This Tight)

> Build a **reliable exam + marking + result system for ONE school**

Ignore for now:

* AI proctoring
* Camera/mic monitoring
* National scaling

---

# 🧱 MVP FEATURES (ONLY WHAT MATTERS)

## **1. Authentication + Roles**

Users:

* Student
* Lecturer
* Admin

👉 Must have:

* Login / signup
* Role-based dashboards

---

## **2. Course & Exam Setup**

Lecturer/Admin can:

* Create course (e.g., CSC101)
* Create exam:

  * Title
  * Duration
  * Start/end time

---

## **3. Question System**

Support ONLY:

* MCQ (start simple)
* (Optional later: essay)

👉 Features:

* Add questions
* Add options
* Set correct answer

---

## **4. Exam Taking (CORE)**

Students can:

* Start exam
* Answer questions
* Submit

👉 MUST HAVE:

* **Auto-save answers (very important)**
* Timer
* One attempt

---

## **5. Auto Marking**

* MCQs marked instantly
* Score calculated automatically

---

## **6. Results System (MAIN VALUE)**

* Students see results immediately
* Lecturers see all student scores
* No missing scripts (everything stored)

---

## **7. Basic Admin Panel**

Admin can:

* View users
* View exams
* View results

---

🎯 Core Users in Your System
1. Students

👉 End users who take exams

What they can do:
Log in
View enrolled courses
Start exams
Answer questions
Submit exams
View results
What they CANNOT do:
Create exams
See other students’ results
Edit anything
2. Lecturers / Examiners

👉 Academic staff responsible for teaching and assessment

What they can do:
Create courses
Create exams
Add/edit questions
View student submissions
View results
(Later)
Mark essay questions
Moderate results
What they CANNOT do:
Manage all users (that’s admin)
Access other lecturers’ courses (unless permitted)
3. School Admin (Department / Faculty Admin)

👉 System managers at the school level

What they can do:
Create/manage users (students + lecturers)
Assign lecturers to courses
View all exams and results
Monitor activity
What they CANNOT do:
Change answers after submission (for integrity)
⭐ 4. (Optional but Very Important) Super Admin

👉 You / system owner OR central exam body

What they can do:
Manage all schools
Full system access
Configure platform settings

👉 Not required for MVP, but useful later when scaling.
# 🎯 FINAL ANSWER

> Your MVP should be a simple, reliable online exam system with role-based access, MCQ exams, auto-marking, and instant results. Focus on eliminating missing scripts and speeding up marking before adding complex features like AI proctoring or multi-institution support.
